cellmap_flow.review_index

Build a review index, the SQLite file the dashboard’s Review tab opens, from an instance segmentation.

python -m cellmap_flow.review_index LABELS OUT.sqlite [–queue NAME …]

LABELS is anything ImageDataInterface reads (zarr v2/v3, N5, precomputed; a multiscale group is read at its finest level), with 0 as background. The index has the schema cellmap_flow.review reads: one instances row per label with its voxel count, bounding box (voxels, half-open) and centroid (voxels, and in world nm), plus one rank_<queue> column per queue; one empty ledger row per label; and meta.

The volume is read in blocks of whole chunks and only per-label sums are kept, so it need not fit in memory.

Queues are chosen with --queue from QUEUES. Other orderings are data: any rank_<name> column added to instances later (say, from per-instance intensity) shows up in the tab as a queue called <name>.
