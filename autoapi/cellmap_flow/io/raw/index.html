cellmap_flow.io.raw

The raw data as a model reads it: a worldarray array through the input chain.

open_raw(path, voxel_size) opens, with worldarray, the level a model at voxel_size reads: the level of a multiscale group or precomputed volume for that size (the finest no coarser than it), the path of one level as it is. When no level is at that size the level found is read as if it were (“relabel”: voxel for voxel, its corner rescaled, with a warning) or resampled to it (resample=True). What comes back is a plain worldarray.WorldArray: voxel_size and corner (nm, spatial axes), shape (every axis), read and read_index; spatial_shape and spatial_axes pick out its spatial part.

RawInput is what a model reads its input from, and what a config’s process_chunk(idi, roi) or predict script is given: to_ndarray_ts(roi) is the world box roi through the input chain, the normalizers (and ChannelSelector) given as input_norms, else the process’s chain (process_chain().input_norms) as it is at read time, which scripts rely on. The inference server reads with serving.chunkmirage_ops.BlockInput, the same protocol over the block chunkmirage read for a chunk.

cellmap_flow.io.raw.open_raw(path, voxel_size=None, resample=False, padding='edge', context=None) → worldarray.WorldArray

The level of path a model at voxel_size reads, open.

voxel_size (nm, z, y, x) picks the level of a multiscale group or precomputed volume: the finest not coarser than it (worldarray’s “floor”), or with resample the coarsest not coarser than it on any axis, else the finest. The path of one level, or of an array, is read as it is. Without a voxel size a group’s first level is opened.

When the level is not at voxel_size, reads are relabelled (the default, with a warning: the level is read voxel for voxel as if it were at voxel_size, so the data really lies where its source_voxel_size and source_translation say and corner is its own corner rescaled) or, with resample, resampled to it by worldarray (labels by the nearest voxel, intensities linearly), from the level’s own corner. resampled tells the two apart; voxel_size is the size reads are at either way.

padding is what a read past the array is padded with, after the chain: “edge” (the default), the array’s outermost voxels repeated, is what a model’s input is read with, since a flat fill is a wall the model never saw in training; 0 for anything else. The reads go through one tensorstore reader thread and no cache (worldarray’s capped_context(network=False)) unless context says otherwise.

class cellmap_flow.io.raw.RawInput(array: worldarray.WorldArray, input_norms=None, normalize=True)

What a model reads its input from: array (the level a model reads, open_raw’s) through the input chain.

input_norms is the chain reads go through, the normalizers and the ChannelSelector; None follows the process’s chain (process_chain().input_norms) as it is at each read, so a worker that unpickles one reads its own chain, not the sender’s. normalize=False reads the channel the chain selects as it is stored, through no normalizer: the finetune trainer and the AI-annotate reader normalize for themselves.

to_ndarray_ts(roi) → numpy.ndarray

The world box roi (nm, half-open; a funlib Roi, a worldarray Box or a (begin, end) pair) through the chain: the channel the chain selects of a multichannel array, the normalizers applied unless normalize is off, and past the array what open_raw’s padding says, added after the chain, so padding is never normalized. A voxel is read when its centre lies in the box (worldarray’s rule). An array that resamples is resampled first, then goes through the chain, as a stored level at that voxel size would.

read_index(begin, end) → numpy.ndarray

Voxels [begin, end) on the array’s spatial grid (its resampled grid when it resamples), read as to_ndarray_ts reads them.
