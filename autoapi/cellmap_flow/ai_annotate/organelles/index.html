cellmap_flow.ai_annotate.organelles

What the model is told about each structure it can be asked to paint.

A catalog of organelles: the colour to ask the model to paint each one, and a description of how it looks in EM to ground the request in what the structure actually looks like. Adapted from ask-to-mask’s ORGANELLES catalog, keeping only the fields this feature uses. A label name the catalog does not know still works (resolve_organelle_profile), just without a description.

The colours are distinct within the catalog but need not be unique across it (cells and mitochondria are both red): one request asks for one structure.
