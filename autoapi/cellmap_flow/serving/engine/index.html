cellmap_flow.serving.engine

Which inference server a process runs: chunkmirage’s or the Flask one.

CELLMAP_FLOW_ENGINE is chunkmirage (the default) or flask. Every place that starts a server (cellmap_flow serve, infer --server-check and the finetune loop) builds it with make_server, and both take the same arguments.

A model can run in an environment of its own (its env: a pixi environment, an alias or a path), which may not have chunkmirage. Unless chunkmirage was asked for, such a server is the Flask one, with a warning; the dashboard draws either server’s layers.
