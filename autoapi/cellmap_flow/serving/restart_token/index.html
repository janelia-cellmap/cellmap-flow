cellmap_flow.serving.restart_token

The shared secret that authorizes restarting a finetune job over HTTP.

A job’s embedded inference server accepts POST /__control__/restart, and a restart can change what the job trains on, so it must not be callable by anyone who can reach the node. The job manager writes a random token into the job’s output directory before submitting it, readable only by the user; the training process reads it from there and the dashboard sends it with every restart. It never goes on the command line, where bjobs -l would show it to other users of the cluster.
