cellmap_flow.finetune.trainer.distillation

The distillation term: its weight, where it applies, and the teacher.

Distillation holds the model to the one it started from where the paint says nothing: on the unlabeled voxels, on every voxel, or on the good regions’ anchor patches when the session has any (losses.distillation_loss). The teacher is the model as it was before this run changed it: with LoRA the same module with its adapter switched off, for a full finetune a frozen copy of the starting weights (adaptation’s strategies). The browser’s twin is web/src/finetune/distillation.ts.

class cellmap_flow.finetune.trainer.distillation.Distillation(options, *, anchors_available, model, strategy, device, precision)

The distillation term of a run, from its TrainingOptions.

The weight: distillation_lambda, or when that is None (unset) 1.0 if the dataset emits anchors (good regions, or random points of the volume) and 0 otherwise. Good regions are useless without a teacher term to apply in them: the supervised loss never touches an unannotated voxel, so with lambda at 0 every rehearsal patch would contribute exactly nothing and the regions the user marked would silently do nothing at all. Marking them is an explicit request to be held there. An explicit 0 is honoured: it used to be indistinguishable from “unset” and was raised to 1.0 as well, so choosing “0 (Disabled)” in the dashboard with good regions marked gave 100x the default weight.

property teacher_model

A full finetune’s frozen teacher, the copy of its starting weights; else None.

The CLI hands it to the next iteration’s trainer. Setting it to None frees it (drop does, with the term).

drop()

Switch the term off for good: the OOM handler’s last resort. A full finetune’s frozen teacher is a whole second copy of the weights, freed with the term it served.

teacher_prediction(raw)

The starting model’s prediction on raw.

LoRA: the model itself with its adapters switched off, in eval mode. Full finetune: the frozen copy taken before training. Only called while the term is on, and the teacher is made whenever it is (only drop takes it away). Making one here instead would be wrong for a full finetune: it would copy the student as it is now, not as it started.

term(pred, teacher_pred, mask, anchor)

The mean squared distance of pred from teacher_pred over the term’s scope.

Good regions decide where the teacher is worth copying. Distilling on every unlabeled voxel instead anchors hardest right beside the scribbles, which is the one place the teacher is known to be wrong, so it partly fights the correction being made; with anchors the term is restricted to the regions the user actually vouched for.
