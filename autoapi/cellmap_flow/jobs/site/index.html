cellmap_flow.jobs.site

The numbers that are about the cluster, not about cellmap-flow.

Which GPU queues to offer, how many cores a job asks for, how long it may run, and how long to wait on LSF: all of it is Janelia’s, and it was spread through the launch code as literals. It lives here so that the reasons sit next to the numbers, and so that another site means another profile rather than a search for “gpu_h100”.

Only JANELIA exists. current_site() is the one place that will pick between profiles once there is more than one.
