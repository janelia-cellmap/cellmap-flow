Load Annotated Crops from YAML

Bulk-load externally annotated zarr crops as _chunk_*.zarr entries that train alongside painted chunks. Voxel size, ROI offset and shape are auto-read from each zarr's OME-NGFF metadata; the raw read snaps to the closest available scale of the current dataset.

Either pick a YAML file here, or paste the manifest below. If both are filled, the textarea wins.
Bare strings default to fg_ids=all_nonzero, mode=dense. Per-entry overrides: fg_ids, bg_ids, mode (dense|sparse), connected_components (bool). Top-level: patches_per_epoch, jitter_voxels. Imported crops are written into the session's annotation volume and trained on via FG-anchored random patches.
